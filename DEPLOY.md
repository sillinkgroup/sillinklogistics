# Deploy to Vercel

1. Extract the ZIP, or upload the ZIP directly to Vercel Drop.
2. If Vercel asks for a framework, choose Next.js.
3. Build command: `npm run build`.
4. Start command: `npm start` (Vercel handles this automatically for Next.js).
5. No environment variables are required for the demo.

For a persistent production backend, add a database and environment variables in Vercel Project Settings.
